This repo contains files related to Dusty, the VHS wood CNC router.

- The repo is in a state of flux during the CNC rebuilding project
  - Files may move, disappear, or be created in large quantities
  - The machine name and repo name will change on release
  - It is always worth verifying with the project manager if you have up-to-date information
- Primary software used:
  - CAD software capable of reading/writing STEP files (such as FreeCAD, Rhino, Solidworks or Fusion360)
  - Draw.io (desktop or online) FOSS diagram software
  - Apple Numbers (an .xlsx export of the wiring chart exists for those who cannot access the main document, but should not be updated directly… this needs to be rectified)
- Notable files in the repo:
  - [Wiring Chart & BOM](https://github.com/vhs/dusty-cnc/blob/main/documentation/wiring-diagram/Dustie%20Wiring%20Chart.numbers) ([or read-only excel format](https://github.com/vhs/dusty-cnc/blob/main/documentation/wiring-diagram/Dustie%20Wiring%20Chart.export.xlsx))
  - [Wiring Diagram](https://github.com/vhs/dusty-cnc/blob/main/documentation/wiring-diagram/Wiring%20Diagram.drawio)
  - [CAD Assembly](https://github.com/vhs/dusty-cnc/blob/main/cad/Dustie%20Assembly.step) (not up to date)
